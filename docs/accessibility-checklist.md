# 無障礙驗收矩陣

| 測項 | iPhone | iPad | 驗收方式 |
|---|---|---|---|
| AX1–AX4 | 通過 | 通過 | SwiftUI Dynamic Type、自適應捲動與彈性欄寬。 |
| AX5 | 通過 | 通過 | UI 測試確認首尾答案皆可達；iPhone 截圖人工檢視。 |
| VoiceOver | 通過 | 通過 | 題目、圖片、進度與正誤均有文字標籤；證據揭曉移焦。 |
| 粗體文字 | 通過 | 通過 | 不使用固定高度承載長文，主要內容可換行。 |
| 增加對比 | 通過 | 通過 | 重要文字使用 primary；正誤另有文字、圖示及 2pt 邊框。 |
| 減少動態 | 通過 | 通過 | 依 `accessibilityReduceMotion` 關閉答題與 HP 動畫。 |
| 不以顏色傳意 | 通過 | 通過 | 正確、錯選、鎖定、完成皆有文字與 SF Symbol。 |
| 觸控目標 | 通過 | 通過 | 核心答案按鈕最小高度 48pt。 |
